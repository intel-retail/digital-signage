# Digital Signage: Context-Aware, Cross-Selling

## Overview
The Context-Aware, Cross-Selling Digital Signage application is a fully containerized edge AI solution for product detection and dynamic advertisement generation using Intel AI and media pipelines. Refer to the [Digital Signage user guide](./docs/user-guide/index.md) for details.
