# API Reference

## AIG API

**Base URL:** `http://<HOST_IP>:<AIG_PORT>`

### `POST /aig/minf/`
Generates an advertisement image from text and optional overlays.

### `POST /ase/predef/`
Stores a predefined advertisement in the ad search database.

### `POST /ase/predef/query/ad`
Queries matching predefined advertisements.

## PID API

**Base URL:** `http://<PID_HOST>:8080`

For full PID API documentation, see:
