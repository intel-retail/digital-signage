## Quick Flow

1. Validate your host against the [system requirements](./get-started/system-requirements.md).
2. Download required AI models.
3. Build container images.
4. Configure `.env` and optional product associations.
5. Deploy with Docker Compose.
6. Access the Web UI and verify service health.
