# System Requirements

## Minimum Hardware

- **CPU:** Intel(R) Core(TM) Ultra (Series 2) processor or above with at least 16 cores
- **RAM:** 16 GB minimum (32 GB recommended)
- **Disk:** 500 GB free space
- **GPU:** Intel® integrated GPU

## Software

- **OS:** Ubuntu 24.04 LTS
- **Docker:** Docker Engine 24.x+
- **Docker Compose:** v2
- **Network:** Internet access for model downloads and image pulls
