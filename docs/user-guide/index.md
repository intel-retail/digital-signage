# Digital Signage

The Context-Aware, Cross-Selling Digital Signage application is a containerized edge AI solution for real-time product detection and dynamic advertisement generation.

## Core Services

- **PID (Product Identification):** Detects products from video streams using DL Streamer Pipeline Server.
- **AIG (Advertise Image Generator):** Generates dynamic advertisements with GenAI models.
- **ASe (Advertise Searcher):** Retrieves relevant predefined ads from vector search.
- **Web UI:** Displays live stream and current advertisements.
